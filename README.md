GAMEFINITY MOBILE CONTROLE V3 — MAC CORRIGIDO

1. Instale Node.js 18+.
2. Extraia o ZIP.
3. Na primeira execução, Control + clique em INICIAR_GAMEFINITY.command > Abrir > Abrir.
4. O servidor inicia e abre automaticamente o POS e a página para ligar o celular.
5. No celular, use o endereço http://IP-DO-MAC:8787 mostrado na página.
6. PIN padrão: 1234.

Se o macOS continuar a bloquear, veja COMO_INICIAR_NO_MAC.txt.

O servidor usa SSE para atualização em tempo real.
